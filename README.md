# Eagonshop

Create a premium, modern, and highly aesthetic fashion eCommerce website for my clothing brand.

Brand Name: Eagon Shop

Website Goal:

Sell Western Wear and Indian Wear for women at affordable retail prices. The website should look luxurious like Zara, H&M, Mango, and Nykaa Fashion while keeping the products budget-friendly.

Design Style:

- Minimal and elegant

- Luxury black, white, beige, and gold color palette

- Soft shadows and glassmorphism effects

- Smooth animations and page transitions

- Clean typography (Poppins or Manrope)

- Fully responsive for mobile, tablet, and desktop

- Fast loading and SEO-friendly
